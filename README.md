# CodeNest

CodeNest is a real-time team collaboration platform inspired by Slack and Discord.

It allows users to create workspaces, communicate through workspace channels and direct messages, and collaborate in real time.

> 🚧 This project is currently under active development.

---

## Features

### Authentication
- User authentication with Better Auth
- Protected routes
- Session management

### Workspaces
- Create workspaces
- Navigate between workspaces
- Workspace conversations

### Direct Messages
- Start conversations with other users
- Reuse existing conversations
- Sidebar with recent DMs

### Messaging
- Send messages
- View conversation history
- Shared chat component for workspace and DM conversations
